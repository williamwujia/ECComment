# 电商评论更新助手

这是一个独立 Chrome 扩展，用日常 Chrome 登录会话批量采集淘宝、天猫和京东
商品的最新评价，并输出服务器现有“数据更新”页面可直接导入的 UTF-8 CSV。

它不会替换 `chrome_extension/` 中的京东专用采集器。两个扩展使用不同的名称、
目录、存储键和下载文件名，可以同时安装；京东页面变化时仍可单独使用旧采集器兜底。

## 安装

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `ecommerce_review_assistant`。
5. 固定“电商评论更新助手”。

## 使用

每行输入一个“商品 URL,目标数量”：

```text
https://detail.tmall.com/item.htm?id=123456789,200
https://item.taobao.com/item.htm?id=987654321,200
https://item.jd.com/13745188.html,200
```

点击“开始新任务”后，助手会逐个打开商品、进入评价区域、尝试切换到最新排序、
采集并写入本地检查点。遇到登录页时任务会暂停；扫码登录后会自动重试，也可点击
“登录后继续”。单个商品失败不会丢失此前结果，也不会阻止队列继续。

天猫或淘宝偶尔会对直接打开的裸商品 URL 返回不含评论模块的简化页面。此时请从
站内正常打开一个能看到“查看全部评价”的商品页，在扩展文本框第一行保留所需数量
（省略时默认 20），然后点击“采集当前商品页”。该模式复用当前标签页，不再创建直达页。
若评论是直接铺在商品页内而不是抽屉中，只有该模式会在确认已识别到评论卡片后滚动
当前页面；自动直达队列仍禁止盲目滚动商品主页面。

任务结束会下载 `ecommerce_reviews_<时间>.csv`。在服务器中选择对应项目，进入
“维护后台 → 数据更新”，上传 CSV，先执行“检查更新”，核对商品 ID、预计新增量、
重复量和边界状态，再确认写入。

## 运行建议

- 默认每 7 天运行一次；高活跃商品可缩短到 3–7 天，低活跃商品可延长到 14 天。
- 首次采集建议每商品 100–300 条；后续由服务器增量去重。
- 当前版本每个商品最多请求 2000 条，避免误输入导致长时间滚动。
- 找不到评价滚动层或下一页按钮时会安全停止，不会回退为滚动商品主页面。
- 直达页没有评论模块时会提示改用“采集当前商品页”，不会把空白页或预览评论当成成功结果。
- 淘宝和天猫页面选择器必须用真实登录页面持续验证；平台改版后应先更新选择器，
  不要通过增加盲目滚动次数掩盖结构变化。

## 与京东专用采集器的关系

- 综合助手：`ecommerce_review_assistant/`，下载 `ecommerce_reviews_*.csv`。
- 京东兜底：`chrome_extension/`，下载 `jd_reviews_*.csv`。
- 两种 CSV 都复用同一服务器预览、去重、分析、备份和写入流程。
